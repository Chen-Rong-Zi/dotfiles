# :Run 隐式 shell 化实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `:Run` 支持完整 shell 语义（管道、重定向、引号、`$VAR`），term 与 debug 模式均经 `&shell -c` 执行；命令逐字保留；`%` 路径 shellescape。

**Architecture:** `ParseRunArgs` 改收 `<q-args>`（单字符串、逐字含引号/管道/多空格）并按前缀识别 `-i`/`-d`/`--once`；`BuildCommand` 用 `split()/join()` + `shellescape()` 替换 `%`（避开 substitute 替换串元字符污染）；`term_start`/`job_start` 改传 `[&shell, &shellcmdflag, cmd]` 列表强制走 shell。显示层（`last_cmd`/`g_run_prefill`/预填）保持裸命令。

**Tech Stack:** Vim 9.1 vim9script（唯一改动文件 `vim/functions/mode.vim`）；headless 测试 `vim -es -u NONE`（import 模式、term_getline / getqflist 观测）。

**仓库与分支：** 所有改动与提交在 `/Users/macbook/.dotfiles` 的 `macos` 分支（非默认分支，既有提交均在此）。

```vim
def ParseRunArgs(raw: string)
    const tabid = ModeManager.GetTabID()
    # <q-args> 传入单字符串（逐字含引号/管道/多空格）；仅识别前缀标志 -i/-d/--once
    var line = trim(raw)
    var once = false
    var mode = 'term'
    while line !=# ''
        const first = matchstr(line, '^\S\+')
        if first ==# '--once'
            once = true
            line = trim(line[strlen(first) : ])
        elseif first ==# '-d'
            mode = 'debug'
            line = trim(line[strlen(first) : ])
        elseif first ==# '-i'
            mode = 'interactive'
            line = trim(line[strlen(first) : ])
        else
            break
        endif
    endwhile
    if mode ==# 'interactive'
        # 交互模式：注册 autocmd，由映射后的 q: 打开 cmdline 窗口并预填默认命令
        autocmd CmdwinEnter * ++once setline('.', (g_run_prefill ==# '' ? 'Run io -m -eq %' : 'Run ' .. g_run_prefill)) | cursor(0, line('.'))
        return
    endif
    if mode ==# 'debug'
        if line ==# ''
            # 无后续命令：复用上次保存的命令（空则回退 &makeprg）
            if g_run_prefill !=# ''
                ModeManager.Debug(tabid, g_run_prefill)
            else
                ModeManager.Debug(tabid)
            endif
            return
        endif
        if !once
            g_run_prefill = line
        endif
        ModeManager.Debug(tabid, line)
        return
    endif
    # term 模式
    if line ==# ''
        # 无参数：自动运行上次命令（term 模式），首次默认 io -m -eq %
        const auto_cmd = g_run_prefill ==# '' ? 'io -m -eq %' : g_run_prefill
        ModeManager.Run(tabid, auto_cmd)
        return
    endif
    if !once
        g_run_prefill = line
    endif
    ModeManager.Run(tabid, line)
enddef
```

并把 mode.vim:838 的命令定义改为：

`CommandRunner.BuildCommand`（108-111 行）改为：

```vim
    def BuildCommand(): string
        # 将 cmd_template 中的 '%' 替换为当前文件绝对路径（shellescape 处理空格/$/引号；
        # 用 split/join 而非 substitute，避免替换串元字符 & \ ~ 污染 shellescape 输出）
        return split(this.cmd_template, '%', true)->join(shellescape(this.filepath))
    enddef
```

`DebugMode.BuildCommand`（542-551 行）改为：

```vim
    def BuildCommand(): string
        # 若用户通过 ModeManager.Debug 提供了自定义命令则用之，否则用 &makeprg
        if this.cmd_template !=# ''
            return split(this.cmd_template, '%', true)->join(shellescape(this.src_path))
        endif
        return this.makeprg
            ->split(' ')
            ->map((_, token) => (token =~# '\v\%.*') ? shellescape(this.src_path) : token)
            ->join(' ')
    enddef
```
